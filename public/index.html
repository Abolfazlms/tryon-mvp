۱. مشخصات شما

اندازه‌های دقیق‌تر (اختیاری)

عکس شما (اختیاری)

عکس فقط در مرورگر شما می‌ماند و به جایی فرستاده نمی‌شود، مگر «حالت هوش مصنوعی» را خودتان روشن کنید.

پیش‌نمایش

مانکن فقط نمای تقریبی اندازه و رنگ است. تصویر واقعی‌تر با حالت هوش مصنوعی ساخته می‌شود.

۲. انتخاب لباس

    حالت هوش مصنوعی (آزمایشی)

    عکس شما و تصویر لباس‌ها از مرورگر شما به یک Space عمومی روی Hugging Face فرستاده می‌شود. سهمیه‌ی GPU حساب رایگان کم است (حدود چند تصویر در روز) و مدل‌ها فقط برای استفاده‌ی غیرتجاری‌اند. کفش پشتیبانی نمی‌شود.

    توکن را از huggingface.co/settings/tokens بگیرید. فقط توکن Read یک‌بارمصرف بگذارید. بدون توکن هم کار می‌کند ولی سهمیه کمتر است.

    عکس واقعی لباس‌ها (پیشنهادی)

    کاتالوگ نمونه عکس ندارد و فقط یک آیکن ساده می‌فرستد؛ نتیجه ضعیف می‌شود. برای هر لباس انتخاب‌شده یک عکس تخت روی زمینه‌ی سفید بدهید.

    
      
    

      
    
        
    عکس شما و تصویر لباس‌ها مستقیماً از مرورگر به API گوگل (Gemini) می‌رود. کلید خودتان لازم است و هزینه‌ی هر تصویر (حدود 4 سنت) به حساب شما می‌خورد. Gemini API در همه‌ی کشورها، از جمله ایران، در دسترس نیست.
    
        
      
    

      
      
    این صفحه برای آزمایش است. نسخه‌ی تولیدی باید از سرور خودمان استفاده کند تا کلید پنهان بماند.
    
      
    
        
        
      
    
    
    
      

  
    
    
    قیمت‌ها و فروشگاه‌ها نمونه‌اند. جدول سایز عمومی است و جایگزین جدول هر برند نمی‌شود.
